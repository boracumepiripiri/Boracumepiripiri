# BoraCumê

Site de pedidos do BoraCumê — macarrão cremoso de Piripiri, PI.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:5173

## Deploy no GitHub Pages

1. Suba este código em um repositório GitHub
2. Vá em **Settings → Pages → Source: GitHub Actions**
3. Faça um push na branch `main`
4. O deploy acontece automaticamente

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
